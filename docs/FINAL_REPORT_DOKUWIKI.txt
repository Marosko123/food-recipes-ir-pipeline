===== 1. Prehľad systému =====

==== 1.1 Architektúra ====

Systém pozostáva zo 6 hlavných komponentov:

  - **Crawler** - sťahuje HTML stránky z Food.com
  - **Parser** - extrahuje štruktúrované dáta z HTML
  - **Spark Wikipedia Parser** - spracováva Wikipedia XML dump
  - **Enricher** - prepája recepty s Wikipedia entitami
  - **Indexer** - vytvára invertovaný index (PyLucene)
  - **Searcher** - vyhľadáva v indexe s BM25/TF-IDF

==== 1.2 Dátové zdroje ====

^ Zdroj ^ Popis ^ Počet záznamov ^
| Food.com | Recepty s ingredienciami a postupom | 5,646 receptov |
| Wikipedia | Kulinárne články (enwiki dump) | 9,693 článkov |
| Gazetteer | Entity pre linking (vrátane redirectov) | 42,837 entít |

===== 2. Crawler =====

==== 2.1 Implementácia ====

Crawler je implementovaný v ''crawler/run.py'' a dodržiava tieto pravidlá:
  * Rešpektuje ''robots.txt'' cieľovej domény
  * Dodržiava politeness delay (1 sekunda medzi requestami)
  * Ukladá HTML súbory do ''data/raw/www.food.com/''

**Kľúčový kód - robots.txt parser:**
<code python>
class RobotsParser:
    def __init__(self, domain: str):
        self.rules = {}
        robots_url = f"{domain}/robots.txt"
        response = requests.get(robots_url)
        self._parse_robots(response.text)
    
    def can_fetch(self, url: str, user_agent: str = '*') -> bool:
        for pattern in self.rules.get('disallow', []):
            if re.match(pattern, url):
                return False
        return True
</code>

==== 4.2 Filtrovanie kulinárnych článkov ====

Články sú filtrované podľa:
  * **Infobox patterns:** Infobox food, Infobox prepared food, Infobox ingredient
  * **Category patterns:** Foods, Dishes, Ingredients, Cuisine, Cooking techniques
  * **Food signals:** food, cuisine, dish, ingredient, cooking, culinary, recipe

**Kľúčový kód - detekcia food článkov:**
<code python>
INFOBOX_PATTERNS = [
    re.compile(r'{{\s*Infobox\s+food', re.IGNORECASE),
    re.compile(r'{{\s*Infobox\s+prepared\s+food', re.IGNORECASE),
    re.compile(r'{{\s*Infobox\s+ingredient', re.IGNORECASE),
]

FOOD_SIGNALS = ['food', 'cuisine', 'dish', 'ingredient', 'edible', 
                'cooking', 'culinary', 'recipe', 'meal', 'beverage']

def is_food_related(title, text, categories):
    # Check for food infobox
    if any(pattern.search(text) for pattern in INFOBOX_PATTERNS):
        return True
    # Check categories for food signals
    cat_words = set(word for cat in categories for word in cat.lower().split())
    return len(set(FOOD_SIGNALS) & cat_words) >= 2
</code>

===== 5. Recipe Enricher (Entity Linking) =====

==== 5.1 Aho-Corasick algoritmus ====

Na prepojenie receptov s Wikipedia entitami používame Aho-Corasick algoritmus, ktorý umožňuje efektívne multi-pattern vyhľadávanie.

**Prečo Aho-Corasick:**
  * Časová zložitosť O(n + m + z) - lineárna
  * n = dĺžka textu, m = súčet dĺžok všetkých patterns, z = počet nájdených výskytov
  * Vhodný pre 42,837 entít v gazetteeri

**Kľúčový kód - budovanie automatu:**
<code python>
import ahocorasick

class RecipeEnricher:
    def __init__(self, gazetteer_path, wiki_jsonl_path):
        self.automaton = ahocorasick.Automaton()
        
    def _build_automaton(self):
        # Načítanie gazetteera (surface -> wiki_title mapping)
        for surface, wiki_title in self.surface_to_title.items():
            self.automaton.add_word(surface.lower(), (surface, wiki_title))
        self.automaton.make_automaton()
    
    def find_entities(self, text: str) -> List[Dict]:
        text_lower = text.lower()
        matches = []
        for end_pos, (surface, wiki_title) in self.automaton.iter(text_lower):
            start_pos = end_pos - len(surface) + 1
            matches.append({
                'surface': surface,
                'wiki_title': wiki_title,
                'type': self.title_to_type.get(wiki_title),
                'origin_country': self.wiki_articles[wiki_title].get('origin_country'),
                'abstract': self.wiki_articles[wiki_title].get('abstract', '')[:500]
            })
        return matches
</code>

==== 5.2 Proces obohacovania ====

Pre každý recept:
  - Spojenie textových polí (title + ingredients + instructions + description)
  - Vyhľadanie všetkých entít pomocou Aho-Corasick
  - Pridanie ''wiki_links'' s abstraktami a metadátami
  - Inferencia kuchyne podľa pôvodu ingrediencií
  - Pridanie historického kontextu ak je k dispozícii

===== 6. Indexer (PyLucene) =====

==== 6.1 Schéma indexu ====

Index používa PyLucene (cez Lupyne wrapper) s BM25 podobnosťou.

**Textové polia (full-text search s tokenizáciou):**

^ Pole ^ Boost ^ Popis ^
| title_text | 2.0 | Názov receptu |
| ingredients_text | 1.5 | Zoznam ingrediencií |
| instructions_text | 1.0 | Postup prípravy |
| wiki_abstracts | 1.0 | Spojené Wikipedia abstrakty |

**Keyword polia (exact match, bez tokenizácie):**

^ Pole ^ Popis ^
| ingredients_kw | Presné vyhľadávanie ingrediencií |
| cuisine_kw | Filtrovanie podľa kuchyne |
| origin_country_kw | Filtrovanie podľa krajiny pôvodu |
| origin_region_kw | Filtrovanie podľa regiónu |

**Numerické polia:**

^ Pole ^ Popis ^
| total_minutes | IntPoint pre range queries (čas prípravy) |

**Stored polia (neuložené v indexe, len pre zobrazenie):**

^ Pole ^ Popis ^
| docId | Unikátny ID receptu |
| url | URL na Food.com |
| description | Popis receptu |
| nutrition | Nutričné hodnoty (JSON string) |
| ratings | Hodnotenia (JSON string) |

**Kľúčový kód - definícia polí:**
<code python>
class LupyneRecipeIndexer:
    def build_index(self):
        # Text fields - tokenized, indexed, stored
        self.indexer.set('title_text', stored=True, 
                         indexOptions='DOCS_AND_FREQS_AND_POSITIONS')
        self.indexer.set('ingredients_text', stored=True, 
                         indexOptions='DOCS_AND_FREQS_AND_POSITIONS')
        self.indexer.set('wiki_abstracts', stored=True, 
                         indexOptions='DOCS_AND_FREQS_AND_POSITIONS')
        
        # Keyword fields - not tokenized (exact match)
        self.indexer.set('ingredients_kw', stored=True, tokenized=False)
        self.indexer.set('cuisine_kw', stored=True, tokenized=False)
        self.indexer.set('origin_country_kw', stored=True, tokenized=False)
        
        # Numeric field for range queries
        self.indexer.set('total_minutes', stored=True, dimensions=1)
</code>

===== 7. Searcher (Vyhľadávač) =====

==== 7.1 Podporované typy dopytov ====

^ Typ dopytu ^ Syntax ^ Príklad ^ Implementácia ^
| Full-text | prosté slová | chocolate cake | BM25Similarity |
| Exact phrase | úvodzovky | "chocolate cake" | PhraseQuery |
| Fuzzy | s preklepmi | chickn → chicken | FuzzyQuery (edit distance 2) |
| Boolean AND | + | chicken +garlic | BooleanClause.MUST |
| Boolean NOT | - | pasta -meat | BooleanClause.MUST_NOT |
| Ingredient filter | include/exclude | include=["egg"], exclude=["milk"] | TermQuery kombinácia |
| Cuisine filter | cuisine_kw | cuisine_kw:"mexican" | TermQuery |
| Time range | max_minutes | total_minutes < 30 | LongPoint.newRangeQuery |

**Kľúčový kód - multi-field search s boost:**
<code python>
def search_bm25(self, query: str, k: int = 10):
    from org.apache.lucene.search.similarities import BM25Similarity
    self.searcher.setSimilarity(BM25Similarity())
    
    # Build query across multiple fields with boosts
    query_parts = []
    for term in query.split():
        query_parts.append(f"title_text:{term}^2.0")      # Title má najvyšší boost
        query_parts.append(f"ingredients_text:{term}^1.5")
        query_parts.append(f"instructions_text:{term}^1.0")
        query_parts.append(f"wiki_abstracts:{term}^1.0")
    
    query_str = " OR ".join(query_parts)
    hits = self.searcher.search(self.searcher.parse(query_str), count=k)
    return self._format_results(hits)
</code>

**Kľúčový kód - ingredient filtering:**
<code python>
def search_by_ingredients(self, include: List[str], exclude: List[str], k: int = 10):
    builder = BooleanQuery.Builder()
    
    # Ingrediencie ktoré MUSIA byť prítomné
    for ing in include:
        builder.add(TermQuery(Term("ingredients_kw", ing.lower())), 
                   BooleanClause.Occur.MUST)
    
    # Ingrediencie ktoré NESMÚ byť prítomné
    for ing in exclude:
        builder.add(TermQuery(Term("ingredients_kw", ing.lower())), 
                   BooleanClause.Occur.MUST_NOT)
    
    return self.searcher.search(builder.build(), count=k)
</code>

==== 7.2 Výkonnostné porovnanie ====

**Priemerné časy vyhľadávania (25 testovacích dopytov):**

^ Algoritmus ^ Index v1 (Simple) ^ Index v2 (PyLucene) ^
| BM25 | **2.36 ms** | 19.61 ms |
| TF-IDF | **1.96 ms** | 13.53 ms |

**Poznámka:** Index v1 je rýchlejší pre malé datasety kvôli absencii JVM overhead. PyLucene škáluje lepšie pre väčšie datasety a ponúka pokročilé features (fuzzy, phrase queries).

**Overlap výsledkov Simple vs Lucene BM25:** **66.8%**

===== 8. Vyhodnotenie a porovnanie =====

Detailné porovnanie všetkých testovaných systémov a metrík nájdete v samostatnom dokumente:

  * **[[user:maros.bednar:vinf:konzultacie:2025-12-15:Detailne_Vyhodnotenie|Detailné Tabulkové Vyhodnotenie Queries]]**

==== 8.1 Metodológia ====

Porovnali sme 6 systémov na 5 testovacích dopytoch. Ground Truth sme vytvorili metódou **pooling** - zozbierali sme top-10 výsledkov zo systémov S1, S2, L1, L2 a Food.com, deduplikovali a manuálne ohodnotili relevanciu.

**Kritérium relevancie:** Dokument je relevantný ak obsahuje hlavnú tému dopytu (typ jedla) + aspoň jeden kľúčový modifikátor.

==== 8.2 Zhrnutie výsledkov ====

^ Systém ^ Mean P@5 ^ ZRR ^ Poznámka ^
| 🥇 **G (Google site:food.com)** | **100%** | 0% | Perfektná presnosť vďaka sémantickému porozumeniu |
| 🥈 **FC (Food.com)** | **80%** | 20% | Produkčný systém, ale ZRR na Q5 |
| 🥉 **S1 (Simple BM25)** | **76%** | 0% | Výborný výkon vďaka boostingu |
| 🥉 **L1 (PyLucene BM25)** | **76%** | 0% | Rovnaký výkon, wiki enrichment |
| 5. **L2 (PyLucene TF-IDF)** | **60%** | 0% | Slabší bez BM25 normalizácie |
| 6. **S2 (Simple TF-IDF)** | **52%** | 0% | Najslabší z našich systémov |

**Kľúčové zistenia:**
  * **Google** dosahuje perfektné výsledky vďaka sémantickému porozumeniu a globálnym signálom (PageRank)
  * **Food.com** má vysokú presnosť ale problém so **Zero Result Rate** (20%) na komplexnejších dopytoch
  * **Naše BM25 systémy (76%)** dosahujú porovnateľné výsledky vďaka inteligentnému boostingu
  * **Boosting** na title (2.0×), ingredients (1.5×) a instructions (1.2×) - v inštrukciách sa opakovane spomínajú ingrediencie, čo zvyšuje skóre relevantných dokumentov
