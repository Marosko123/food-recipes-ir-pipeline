===== 1. Úvod a cieľ projektu =====

Cieľom projektu je implementácia **kompletného Information Retrieval systému** pre vyhľadávanie kulinárskych receptov. Systém kombinuje dáta z dvoch zdrojov - webstránky food.com a anglickej Wikipédie - a umožňuje fulltextové vyhľadávanie s pokročilými filtrami.

==== 1.1 Motivácia ====

Existujúce receptové vyhľadávače (AllRecipes, Food Network) majú niekoľko limitácií:
  * Nedostatok kontextu - chýbajú informácie o histórii a pôvode jedál
  * Slabá filtrácia - naivné keyword matching bez sémantiky
  * Žiadna normalizácia synonymí - "cilantro" nenájde "coriander"

==== 1.2 Riešenie ====

Náš systém rieši tieto problémy pomocou:
  * **Wikipedia integrácie** - obohatenie receptov o kultúrny kontext (Linked Data)
  * **Entity linking** - prepojenie ingrediencií s Wikipedia článkami pomocou Aho-Corasick
  * **Dvojitého indexu** - Simple (Python) + Lucene pre porovnanie
  * **Porter stemming** - normalizácia slov (cooking → cook)

# parser/html_parser.py
def extract_recipe_data(html: str) -> Dict:
    # Nájdi JSON-LD blok
    pattern = r'<script[^>]*type=["\']application/ld\+json["\'][^>]*>(.*?)</script>'
    matches = re.findall(pattern, html, re.DOTALL | re.IGNORECASE)
    
    for match in matches:
        data = json.loads(match)
        if data.get('@type') == 'Recipe':
            return {
                'title': data.get('name', ''),
                'ingredients': data.get('recipeIngredient', []),
                'times': extract_times(data),  # PT1H30M → 90 min

==== 3.2 Z Wikipédie (15 premenných) ====

Spark parser streamuje 20GB XML dump a filtruje kulinárske články:

<code python>
# spark_jobs/enwiki_spark_parser.py
INFOBOX_PATTERNS = [
    re.compile(r'{{\s*Infobox\s+food', re.I),
    re.compile(r'{{\s*Infobox\s+prepared\s+food', re.I),
    re.compile(r'{{\s*Infobox\s+ingredient', re.I),
]

def is_food_article(text: str, categories: List[str]) -> bool:
    # Kontrola infoboxu
    has_food_infobox = any(p.search(text) for p in INFOBOX_PATTERNS)
    if has_food_infobox:
        return True
    
    # Kontrola kategórií
    food_signals = ['cuisine', 'dish', 'food', 'recipe', 'cooking']
    matched = sum(1 for s in food_signals if s in ' '.join(categories).lower())
    return matched >= 2
</code>

**Výsledok:** 9,693 kulinárskych článkov z 6M stránok (0.16%)

===== 4. Entity Linking (Obohatenie) =====

Recepty sa obohacujú o Wikipedia entity pomocou **Aho-Corasick** algoritmu.

==== 4.1 Prečo Aho-Corasick? ====

Namiesto klasického JOIN-u potrebujeme nájsť entity v neštruktúrovanom texte. Aho-Corasick má zložitosť **O(n + m + z)** namiesto O(n × m) pri naivnom prístupe.

<code python>
# entities/recipe_enricher.py
class RecipeEnricher:
    def __init__(self, gazetteer_path: str):
        self.automaton = ahocorasick.Automaton()
        
        # Načítaj 12,000 wiki entít
        for surface, wiki_title, entity_type in load_gazetteer(gazetteer_path):
            self.automaton.add_word(surface.lower(), (surface, wiki_title, entity_type))
        
        self.automaton.make_automaton()
    
    def enrich(self, recipe: Dict) -> Dict:
        text = f"{recipe['title']} {' '.join(recipe['ingredients'])}"
        
        wiki_links = []
        for end_pos, (surface, wiki_title, entity_type) in self.automaton.iter(text.lower()):
            wiki_links.append({
                'surface': surface,
                'wiki_title': wiki_title,
                'type': entity_type  # dish, ingredient, technique, tool
            })
        
        recipe['wiki_links'] = wiki_links
        return recipe
</code>

===== 5. Indexovanie a vyhľadávanie =====

==== 5.1 Simple Index (Pure Python) ====

Invertovaný index implementovaný bez externých závislostí:

<code>
index/v1/
├── terms.tsv      # term → df, idf (14,977 termov)
├── postings.tsv   # term → field, docId, tf (2.5M záznamov)
├── docmeta.tsv    # docId → url, title, time, cuisine
└── field_lengths.json  # pre BM25 normalizáciu
</code>

==== 5.2 BM25 Implementácia ====

<code python>
# indexer/simple_indexer.py
def search_bm25(self, query: str, k: int = 10):
    K1, B = 1.2, 0.75  # Štandardné parametre
    
    for term in tokenize(query):
        df, idf = self.terms[term]
        
        for field, doc_id, tf in self.postings[term]:
            doc_len = self.field_lengths[field][doc_id]
            avg_len = self.avg_lengths[field]
            
            # BM25 vzorec
            score = idf * (tf * (K1 + 1)) / (tf + K1 * (1 - B + B * doc_len / avg_len))
            score *= self.field_weights[field]  # title:3, ing:2, instr:1
            
            doc_scores[doc_id] += score
</code>
